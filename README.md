# FinGaurd
FinGuard is an AI-powered financial intelligence platform designed for customer analytics, transaction risk assessment and anomaly-based fraud detection. The system generates customer and transaction data, performs feature engineering, analyses transaction behaviour and uses Isolation Forest for unsupervised anomaly detection. Suspicious transactions are assigned risk scores and risk levels, which are then converted into alerts. Analysts can explore these alerts through the Fraud Detection and Investigation Center modules and examine the underlying transactions through the Transaction Monitoring module.
